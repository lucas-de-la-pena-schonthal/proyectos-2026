# Muestra Anual de Proyectos | Colegio Schönthal

Bienvenido al repositorio oficial del **Portal Web de Proyectos** del Colegio Schönthal. Este sitio centraliza y exhibe los trabajos prácticos, aplicaciones y desarrollos elaborados por los alumnos de **4° C** y **5° A** a lo largo del ciclo lectivo.

## Descripción del Proyecto

El portal surge como una iniciativa para poner en valor el aprendizaje práctico y el trabajo colaborativo de los estudiantes. Funciona como una vitrina digital interactiva donde se integran los contenidos técnicos y conceptuales abordados en las siguientes asignaturas:

* **Tecnologías de la Información:** Fundamentos digitales, arquitectura web y gestión de la información.
* **Desarrollo de Aplicaciones Informáticas:** Programación, lógica de software, bases de datos y diseño de interfaces (UI/UX).
* **Proyectos de Producción:** Planificación, metodologías de trabajo y ejecución de soluciones tecnológicas orientadas a necesidades reales.

## Características del Portal

* **Catálogo interactivo:** Navegación por curso (4° C y 5° A) y por materia.
* **Fichas de proyecto:** Cada trabajo incluye su descripción, objetivos, stack tecnológico e integrantes del equipo.
* **Acceso a demos y repositorios:** Enlaces directos a las ejecuciones en vivo y al código fuente de cada proyecto.

## Tecnologías Utilizadas

* **Frontend:** HTML, CSS, JavaScript, Jinja
* **Backend:** Flask (Python)
* **Base de Datos:** SQL, SQLite
* **Control de Versiones:** Git
